PRESENTATION
-------------------------------------------------------------------------------

Accelerator Viewer est une application permettant de consulter, comparer et
administrer une base de données des équipements utilisés en radiothérapie.

L'application est entièrement autonome et ne nécessite aucune connexion
Internet pour fonctionner.

Principales fonctionnalités :

 • Consultation des accélérateurs de radiothérapie
 • Recherche rapide d'un équipement
 • Visualisation des caractéristiques techniques
 • Affichage des techniques cliniques supportées
 • Gestion des systèmes d'imagerie
 • Consultation des informations sur les faisceaux
 • Gestion des collimateurs multilames (MLC)
 • Affichage des photographies des équipements
 • Modification des photographies
 • Comparaison de plusieurs accélérateurs
 • Tableau de bord statistique

Les données sont stockées au format JSON afin d'être facilement modifiables
et pérennes.

-------------------------------------------------------------------------------
CONFIGURATION REQUISE
-------------------------------------------------------------------------------

Cette application est fournie avec une version portable de PHP.

Aucune installation de PHP, XAMPP ou WampServer n'est nécessaire.

Systèmes compatibles :

 • Windows 10
 • Windows 11

Navigateur recommandé :

 • Microsoft Edge
 • Google Chrome
 • Mozilla Firefox

-------------------------------------------------------------------------------
DEMARRAGE
-------------------------------------------------------------------------------

1. Décompressez entièrement l'archive ZIP.

2. Ouvrez le dossier :

       Accelerator_Viewer

3. Double-cliquez sur :

       lancer.bat

4. Une fenêtre s'ouvre automatiquement.

5. Votre navigateur Internet démarre et ouvre l'application.

Adresse de l'application :

       http://127.0.0.1:8000

-------------------------------------------------------------------------------
ARRET DE L'APPLICATION
-------------------------------------------------------------------------------

Deux possibilités :

 • Fermer la fenêtre du serveur.

ou

 • Exécuter le fichier :

       arreter.bat
